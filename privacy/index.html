Privacy Policy

How Gmail data is accessed and handled

This policy describes the data practices of Personal Inbox Reminder, a private utility used by one operator.

Effective date
August 27, 2026
Contact
valovodfinder@gmail.com

1. Scope and operator

Personal Inbox Reminder is a non-commercial, personal-use utility operated by the owner of this domain. It is not offered for public account registration and is not affiliated with or endorsed by Google, Gmail, Discord, OpenAI, or Riot Games.

2. Google user data accessed

The app requests only the OAuth scope https://www.googleapis.com/auth/gmail.readonly. The application code uses this permission to retrieve:

  • Gmail message and thread identifiers;
  • sender, recipient, subject, and date headers;
  • limited text from recent messages in a relevant thread;
  • attachment file names, but not attachment file contents;
  • Gmail history identifiers needed to detect newly received inbox messages.

Although the scope can permit broader read-only access, the app is designed to query recent inbox activity and relevant thread context only. It does not request permission to send, modify, label, archive, or delete email.

3. How Google user data is used

Google user data is used solely to identify messages that may require the operator to take action. Examples include an explicit deadline, a direct question, a requested submission, an interview or test preparation item, an account action, or another obligation where inaction may create a problem.

The app does not use Google user data for advertising, credit or lending decisions, user profiling, resale, or generalized AI model training by this application.

4. Processing and disclosure to service providers

The app runs through Hermes Agent on the operator’s personal computer. To classify whether a message requires action, limited thread content may be sent to the AI model provider configured by the operator. The current configuration uses an OpenAI service. AI-provider processing is governed by the applicable provider terms and privacy policy.

When a reminder is warranted, a concise summary may be sent through Discord to a private destination controlled by the operator. The app does not intentionally post full Gmail threads to public channels.

These service providers process data only to provide the reminder workflow selected by the operator. The app does not sell Google user data or disclose it to data brokers or advertising platforms.

5. Local storage and retention

OAuth credentials are stored locally in the operator’s Hermes profile. The collector’s state file stores Gmail message or thread identifiers, a Gmail history cursor, first-seen timestamps, and acknowledgement status so messages are not repeatedly notified.

The collector state does not intentionally persist complete message bodies. However, limited Gmail content and classification results may appear in local Hermes session or log history. Copies sent to the configured AI provider or Discord may be retained according to those services’ policies and the operator’s account settings.

Pending state is retained until the message is acknowledged or the operator deletes the state. A bounded acknowledgement history is maintained to prevent duplicate notifications. Local credentials, state, sessions, and logs are retained until removed by the operator.

6. Security controls

  • The app uses the narrow read-only Gmail scope required for the workflow.
  • OAuth credentials and reminder state are stored on the operator’s computer rather than in this public website.
  • This website does not provide a login form and does not receive Gmail content.
  • The website uses no advertising technology and no analytics or tracking cookies.

No system can guarantee absolute security. The operator maintains responsibility for device security, Google account security, Discord access, and configured AI-provider access.

7. Access, revocation, and deletion

The operator may stop access at any time by revoking the app in the Google Account’s third-party connections or security settings. The operator may also delete the locally stored OAuth token, reminder state, Hermes sessions and logs, and previously delivered Discord messages.

After access is revoked, the app can no longer retrieve new Gmail data unless the operator grants permission again.

8. Google API Services User Data Policy

The app’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes to this policy

This policy may be updated when the app’s functionality, providers, data handling, or legal requirements change. The effective date at the top of this page will be updated when material changes are published.

10. Contact

Questions about this policy or requests concerning locally stored data may be sent to valovodfinder@gmail.com.
